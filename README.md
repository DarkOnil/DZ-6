# 64-v2 — минимальные изменения

Выполнены поиск, сортировка и редактирование товара. Форма добавления товара оставлена почти без изменений, добавлено обновление списка после создания.

## Запуск
1. В папке проекта выполни `npm install`.
2. В первом терминале выполни `npm run server`.
3. Во втором терминале выполни `npm run dev`.

Сервер JSON Server работает с локальным файлом `db.json` на порту 3001.
